MMLU-Pro / MMMU-Pro Model Cost Estimates
Pricing and data checked: 2026-10-10

Column definitions
- Unit price: input / output, in USD per 1M tokens.
- Answer cost/question = average input tokens × input price + average output tokens × output price.
- Verifier cost/question: the average cost for this model to judge one answer from one model; it is not the combined cost of judging all seven other models.
- Both token columns show total tokens (input + output).
- Provider-reported output tokens include hidden reasoning/thinking tokens; R denotes the average number of reasoning/thinking tokens included in the output total.
- Costs use standard, non-batch, non-cached API pricing and exclude failed retries, taxes, regional surcharges, and long-context surcharges.

Open-weight model pricing notes
[1] The experiment used the `meta-llama/Llama-3.1-8B` base checkpoint. Hugging Face Inference Providers does not currently list the exact base endpoint, so the lowest listed price for the same-size Llama-3.1-8B-Instruct model ($0.02/$0.05) is used as a proxy.
[2] Hugging Face Inference Providers does not currently list the exact `Qwen3-30B-A3B-Thinking-2507` endpoint. The DeepInfra price for Qwen3-30B-A3B ($0.12/$0.50) listed by Hugging Face is used as a proxy. This row has greater uncertainty than the others.
- Qwen3.5-35B-A3B, Qwen3-VL-30B-A3B-Instruct, and Llama-4-Scout use the DeepInfra prices that match the provider recorded in the experiment's raw usage, rather than prices from other providers on the Hugging Face page.
